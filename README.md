# Leaguefall ⚔️

A browser-based MOBA prototype inspired by the *design traditions* of League of Legends and Dota 2: lane pressure, champions, abilities, items, waves, gold, XP and tactical decision-making.

## Phase 1

- Premium dark MOBA interface
- Three-lane battlefield presentation
- Playable champion: Astra
- Q/W/E/R abilities
- Mana and health management
- Enemy waves and combat
- Gold, XP and level progression
- Ability upgrades
- Item shop
- Wave progression
- Responsive layout

## Next phases

1. Proper 3-lane real-time simulation with minions and tower targeting
2. Champion roster and selectable roles
3. Dota-style item combinations and active items
4. Jungle camps, neutral objectives and boss monsters
5. Champion abilities with skillshots, crowd control and cooldowns
6. Multiplayer architecture and matchmaking
7. Cloudflare Pages/Workers deployment

The project is intentionally an original game rather than a copy of either source game, using familiar MOBA conventions while developing its own world, characters and systems.
